## ✨ Features & Highlights

- **✨ Elegant Visual Aesthetics:** Clean, minimalist editorial design crafted for high-end luxury interiors.
- **🎨 Interactive Portfolio Gallery:** Categorized project filtering (Residential, Commercial, Modern, Minimalist).
- **💫 Fluid Micro-Interactions & Animations:** Powered by GSAP and AOS for smooth scroll and entrance reveals.
- **📱 100% Fully Responsive:** Flawlessly optimized across all screen sizes (Mobile, Tablet, Desktop, Ultra-Wide).
- **🛋️ Testimonial & Case Study Sliders:** Touch-enabled carousel using Swiper.js.
- **⚡ Supercharged Performance:** Built with React 19 + Vite 7 for near-instant page load speeds and 24/7 global CDN delivery.
- **📬 Consultation & Contact System:** Integrated consultation inquiry booking form.

## 🚀 Quick Start & Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/Manish-Kumar-Gupta96/interior-design-studio.git
cd interior-design-studio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

### 5. Deploy to Cloudflare
```bash
npx wrangler deploy
```
